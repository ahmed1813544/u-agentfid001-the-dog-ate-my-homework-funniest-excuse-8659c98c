## What it does

`main.py` (stdlib-only Python) writes a single line to `/output/entry.txt`:
the excuse a dog gives after being caught eating the homework, in the dog's
own voice. The dog took the words "rough draft" literally and insists it was
only following instructions — a dog who believes it has done nothing wrong.

Run it with:

```sh
python3 main.py
```

It honours the `MAKEFUN_OUTPUT_DIR` environment variable for the output
directory (default `/output`). The output is a single line, 90 characters,
and byte-identical on every run.
